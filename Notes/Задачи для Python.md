- 10:16: 1. Частотный словарь символов / слов
Условие: На вход подается строка текста (например, "error 404 not found error 500 server error").
Задача: Написать код, который подсчитывает количество вхождений каждого слова и сохраняет результат в словарь вида {'error': 3, '404': 1, ...}.
Условие со звездочкой: Решить без использования сторонних модулей (только базовый dict, желательно через метод .get()).
2. Инвертирование словаря
Условие: Дан словарь соответствий вида:
ports = {
    'http': 80,
    'https': 443,
    'ssh': 22,
    'dns': 53
}

Задача: Сформировать новый словарь, где ключи и значения поменялись местами ({80: 'http', ...}).
Усложнение: Что произойдет, если несколько протоколов используют один порт? Переделай логику так, чтобы значениями нового словаря были списки: {80: ['http'], ...}.
3. Слияние складов / логов с суммированием
Условие: Есть два словаря со статистикой запросов за разные часы:
hour_1 = {'api/v1/users': 150, 'api/v1/login': 40, 'api/v1/health': 300}
hour_2 = {'api/v1/users': 80, 'api/v1/logout': 15, 'api/v1/health': 250}

Задача: Объединить эти два словаря в один общий. Если эндпоинт встречался в обоих словарях, их значения должны сложиться, а не просто перезаписаться.
4. Фильтрация через Dict Comprehension
Условие: Дан словарь серверов с их текущей задержкой (ping) в миллисекундах:
servers_ping = {
    'msk-1': 15,
    'spb-1': 42,
    'fra-1': 110,
    'ams-1': 95,
    'hel-1': 65
}

Задача: В одну строчку (через генератор словаря — dict comprehension) создать новый словарь, в который попадут только серверы с задержкой строго меньше 70 мс.
5. Группировка списка по категории
Условие: Дан список кортежей с файлами и их форматами:
files = [
    ('config.yaml', 'config'),
    ('main.py', 'code'),
    ('avatar.png', 'media'),
    ('utils.py', 'code'),
    ('photo.jpg', 'media'),
    ('settings.json', 'config')
]

Задача: Сгруппировать файлы в словарь, где ключ — тип ('code', 'media', 'config'), а значение — список имен файлов, относящихся к этому типу.

    'david': {'age': 29, 'role': 'moderator', 'active': True}

Задача: Найти имя пользователя с максимальным возрастом среди тех, у кого роль 'admin' и статус active == True.
